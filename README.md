# Asteroids Clone - Python

Este repositório contém uma implementação do clássico jogo de arcade **Asteroids**, desenvolvido em Python. O foco do projeto foi aplicar conceitos de programação modular e lógica de jogos 2D.

## 🎮 O Jogo
O objetivo é controlar uma nave num campo de asteroides, destruindo-os para pontuar enquanto evita colisões. 

## 🚀 Funcionalidades e Destaques
- **Arquitetura Modular:** Lógica dividida entre o loop principal (`Asteroids.py`) e funções auxiliares (`funcoes.py`).
- **Mecânicas Clássicas:** Movimentação com inércia, rotação da nave e sistema de disparos.
- **Física de Colisões:** Detecção entre a nave, tiros e asteroides de diferentes tamanhos.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3.x
- **Conceitos:** Programação estruturada, manipulação de vetores e estados de jogo.

## 📖 Como Executar
1. Certifica-te de que tens o Python instalado.
2. Navega até a pasta do projeto.
3. Executa o jogo:
   ```bash
   python Asteroids.py
   ```
